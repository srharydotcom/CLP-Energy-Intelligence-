CLP Energy Intelligence 
Build a production quality React + TypeScript energy intelligence dashboard called “CLP Energy Intelligence”.

Core modules:
1. Energy Passport
2. Consumer “Should I Buy This?”
3. Business Energy Procurement
4. Scenario analysis

Use Supabase as the backend. Make the product a structured decision platform, not a chatbot.

Create reusable components:
EnergyCostCard
LifetimeCostCard
SavingsCard
PaybackCard
EnergyPassportCard
ProductComparisonTable
ScenarioPanel
AIFindingCard
AssumptionPanel

Use synthetic demo data. Do not hardcode fake AI prose. Design the UI to consume structured backend AI JSON
